# Axiom Asset Library Frontend

The full source for the axiomassets.net frontend.

To run this locally, create an `.env` file in the root directory and add `NODE_ENV=development`.

Parts of this codebase are still jank, but that's just because some code was written over a year ago when I first started with web development.

# Contributing

Issues are preferred, but you may also send a pull request.

Feel free to clone this repo and mess about with the code. Because this is just the frontend, it still relies on api.axiomassets.net for api requests.
